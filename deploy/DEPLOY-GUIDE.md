# دليل نشر cto-drs.com — الخطوة الأخيرة (DNS)

> الحالة الحالية: **الموقع مبني ومنشور على GitHub Pages** تحت مستودع
> [`CTO-DRS/cto-drs.com`](https://github.com/CTO-DRS/cto-drs.com)، ومربوط بالنطاق المخصص
> `cto-drs.com` عبر ملف `CNAME`. ما تبقّى فقط: **توجيه سجلات DNS في Spaceship**
> إلى خوادم GitHub Pages.

---

## 1) السجلات المطلوبة (صورة كاملة)

| # | النوع | الاسم | القيمة | TTL |
|---|------|-------|--------|-----|
| 1 | `A` | `@` | `185.199.108.153` | 3600 |
| 2 | `A` | `@` | `185.199.109.153` | 3600 |
| 3 | `A` | `@` | `185.199.110.153` | 3600 |
| 4 | `A` | `@` | `185.199.111.153` | 3600 |
| 5 | `CNAME` | `www` | `CTO-DRS.github.io` | 3600 |

**يجب حذف** سجلَّي A الحاليَّين للجذر (صفحة Parking الخاصة بـ Spaceship):

| النوع | الاسم | القيمة الحالية (للحذف) |
|------|-------|------------------------|
| `A` | `@` | `34.216.117.25` |
| `A` | `@` | `54.149.79.189` |

> هذه العناوين الأربعة هي العناوين الرسمية لـ GitHub Pages
> ([المصدر الرسمي](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site)).

---

## 2) الطريق الأول — آلياً عبر السكربت (يستغرق دقيقة)

يتطلب **زوج مفاتيح Spaceship** (API Key + API Secret — مفتاح واحد لا يكفي؛
يُنشأ الزوج من: spaceship.com → Account → API Keys).

```bash
cd deploy
SS_API_KEY="مفتاحك" SS_API_SECRET="سرك" bash spaceship-dns.sh
```

السكربت:
- يقرأ سجلاتك الحالية، **يحافظ على بريدك (MX/TXT)** وأي سجلات أخرى،
- يستبدل فقط ما يجب استبداله (A@ و www) ثم يعرض النتيجة النهائية.

> 🔐 لا تخزّن المفاتيح داخل أي ملف داخل المستودع — مرّرها كمتغيرات بيئة كما في المثال.

## 3) الطريق الثاني — يدوياً من لوحة Spaceship (5 دقائق)

1. ادخل [spaceship.com](https://www.spaceship.com/) → **Domains** → `cto-drs.com` → **DNS settings**
2. احذف سجلَّي A الحاليَّين (`34.216.117.25` و `54.149.79.189`)
3. أضف سجلات الجدول أعلاه واحداً واحداً (لاحظ: الاسم `@` يعني الجذر)
4. احفظ

---

## 4) بعد تغيير DNS (من 5 دقائق إلى ساعة)

1. تحقق من الانتشار:
   ```bash
   dig cto-drs.com +short        # يجب أن تظهر 185.199.108-111.153
   dig www.cto-drs.com +short    # يجب أن يظهر CTO-DRS.github.io
   ```
2. افتح `https://cto-drs.com` — الموقع يعمل (قد يظهر تنبيه شهادة في الدقائق الأولى
   حتى تُصدر GitHub شهادة Let's Encrypt تلقائياً)
3. من GitHub: **Settings → Pages → Enforce HTTPS** ✓ (يظهر بعد إصدار الشهادة)
4. (اختياري، موصى به) تحقق ملكية النطاق لمنع الاختطاف:
   **GitHub → Settings → Pages → Verified domains → Add** واتبع التعليمات (TXT)

---

## 5) تحديث الموقع مستقبلاً

```bash
cd cto-drs-site
# عدّل الملفات ثم:
git add -A && git commit -m "تحديث" && git push
# يُبنى الموقع تلقائياً خلال دقيقة
```

## 6) ملخص البنية

```
cto-drs.com  ──DNS──▶  GitHub Pages (CTO-DRS/cto-drs.com)
                          ├── index.html      الرئيسية (هيرو + إحصاءات + خدمات + مشاريع)
                          ├── services.html   الخدمات (4 خدمات + منهجية + تقنيات)
                          ├── projects.html   المشاريع (6 مشاريع بشبكة غير متماثلة)
                          ├── contact.html    التواصل (قنوات + نموذج بريدي)
                          ├── 404.html        صفحة الخطأ
                          └── assets/         CSS + JS + خطوط مستضافة ذاتياً (16 ملف woff2)
```

اللغة: عربي افتراضي (RTL) مع زر `EN` فوري — والرابط `?lang=en` يفتح النسخة الإنجليزية مباشرة.
